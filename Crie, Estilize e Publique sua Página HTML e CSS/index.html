04 / REFERÊNCIAS DE PREÇO

De onde vêm os valores?

A abertura equivale a 80% de uma venda documentada de cada modelo, arredondados para baixo ao milhar. Essa regra foi escolhida para a atividade. Os preços são de exemplares específicos, não uma avaliação dos carros das fotos nem uma cotação do mercado brasileiro.
